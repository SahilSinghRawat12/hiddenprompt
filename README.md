# 🔎 HiddenPrompt

> A real-time multiplayer game where players try to guess the prompt based on the AI generated image


**Live Demo:** https://hiddenprompt.vercel.app/

---

##  About

**HiddenPrompt** 

is a real-time multiplayer picture guessing game where players take turns becoming the drawer while the other players try to guess the hidden word.

The twist is that the prompts and images are generated using **AI**.

Players select from AI-generated prompts, an AI-generated image is created for the selected prompt, and the other players have to identify the hidden word as quickly as possible.

The faster you guess, the more points you earn.

---

## How It Works

```text
Create / Join Room
        ↓
   Start the Game
        ↓
 AI generates 4 prompts
        ↓
   Drawer selects
        ↓
 AI generates an image
        ↓
   Image shown to everyone
        ↓
 Players start guessing
        ↓
 Correct guess → Points
        ↓
      Timer
        ↓
    Turn Ends
        ↓
   Next Player Draws
        ↓
   Next Round
        ↓
    Game Over
        ↓
  5 Second Countdown
        ↓
   Game Restarts
